# Wiki

Registro de todo el trabajo y los análisis del proyecto. Cada entrada es un archivo aparte.

## Cómo se escribe una entrada

- Nombre: `AAAA-MM-DD-tema-corto.md` (ej. `2026-09-25-analisis-tabla-usuarios.md`).
- Se escribe a partir de [_plantilla.md](_plantilla.md).
- Al crearla, se agrega una línea al índice de abajo, con la más reciente primero.
- Si la entrada cambia algo estable del proyecto (un endpoint, una tabla, una convención), también se actualiza el archivo del brain que corresponda (`api.md`, `interfaz.md`, etc.). La wiki cuenta *qué pasó*; el resto del brain describe *cómo es hoy*.
